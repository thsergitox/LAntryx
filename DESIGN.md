## Overview
Operate-mode desktop editor. Accepted reference: profiles left, keyboard above, color controls below. Functionality and honest device state outrank ornament.
## Colors
CSS variables implement the normative palette above. Selected RGB is editor data, not a global theme. A spectrum gradient is only a color-input affordance.
## Typography
One system sans family. 14px controls, 12px supporting text, 27px task title, tabular numeric inputs. Key legends are vector illustration.
## Layout
180–208px sidebar; flexible workspace. Workspace scrolls independently; action row remains visible. Minimum 960×680; no mobile imitation.
## Elevation & Depth
Quiet borders on controls. Keycap depth uses a short, soft offset shadow. No decorative glow.
## Shapes
6px controls; rectangular color area; clearly outlined picker markers; original 69-key vector geometry.
## Components
Named profile rows, keyboard preview, saturation/value area, hue slider, HEX/RGB fields, swatches, local-save action. Hardware Apply is disabled with a reason until verified.
## Do's and Don'ts
Keep preview, saved data, simulated results and physical device success distinct. No per-key interactive claim, false connected badge, root GUI, surprise USB operations, inaccessible color-only state or vendor bitmap.
